# JS-DOM
Javascript DOM practice:

Click counter - A button that, when clicked, increases a visible counter on the page by one.
Text toggler - A button that shows/hides another element on the page (use classList.toggle).
Live input echo - A text input that updates another element on the page in real time as the user types, showing what they've typed so far.
Dynamic list - A text input and an "Add" button that lets the user type something and add it as a new list item to an existing list on the page.
